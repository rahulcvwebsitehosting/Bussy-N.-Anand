**Live Demo:** [bussynanand.vercel.app](https://bussynanand.vercel.app)

## About

A modern, responsive single-page portfolio website for Bussy N. Anand, Minister in the Government of Tamil Nadu and MLA for T. Nagar constituency.

Built as a design and development exercise.

## Tech Stack

- React 19
- Vite
- Tailwind CSS
- Framer Motion
- Lucide React

## Features

- Hero section with animated typography
- Bilingual navigation (Tamil/English toggle)
- Political journey timeline
- Constituency information (T. Nagar)
- Contact/grievance section
- Mobile-responsive design

## Setup

```bash
git clone https://github.com/rahulcvwebsitehosting/Bussy-N.-Anand.git
cd Bussy-N.-Anand
npm install
npm run dev
```

## Build

```bash
npm run build
```
